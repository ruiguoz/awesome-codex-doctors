# Diagnostic report

Use the smallest report that preserves these distinctions.

## Problem definition

- observed symptom and exact error;
- expected behavior;
- affected Codex surface, version, platform, and relevant recent change.

## Evidence

List local observations and opened sources. Mark negative evidence when it eliminates a likely cause. Redact sensitive values.

## Assessment

Give the leading diagnosis and confidence. Separate confirmed facts, evidence-backed inferences, and unresolved possibilities.

## Recommended route

For each viable route include:

- official command or community Doctor link;
- why it matches this symptom, version, and platform;
- read-only, reversible repair, or cleanup risk label;
- exact scope and data touched;
- prerequisite, backup, dry-run, and rollback information;
- evidence that would confirm success.

Do not present several undifferentiated tools. Rank them and explain why the first is preferred.

## Unresolved

When blocked, request the minimum missing evidence. Prefer one narrow command or file excerpt over a full log dump.
